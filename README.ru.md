# RDR2FrameGen

DLSS Frame Generation для Red Dead Redemption 2 (сюжетный режим, Vulkan, RTX 40/50).

В игре есть апскейлинг DLSS, но нет генерации кадров. Мод подключает к игре настоящий DLSS-G через
NVIDIA Streamline и даёт ему настоящие данные игры:

- **глубину и векторы движения** из вызова DLSS самой игры;
- **камеру игры** (позиция, поворот, угол обзора; читается каждый тик через ScriptHookRDR2), чтобы
  DLSS-G знал, как сдвинулся вид, а не угадывал по выдуманной камере;
- **кадр без интерфейса**: копия сразу после прохода сцены, до того как нарисован HUD, поэтому
  миникарта, подсказки и субтитры не размываются;
- **сброс истории** на склейках камеры (монтаж катсцен, быстрое перемещение, телепорт).

Итог: генерация 2x, один сгенерированный кадр на один отрисованный.

Только для сюжета. **В Red Dead Online с установленным модом не заходите.**

English version: [README.md](README.md).

## Что нужно

- Видеокарта RTX 40 или 50, свежий драйвер NVIDIA.
- В игре: API **Vulkan**, включён **DLSS** (любой режим качества), вертикальная синхронизация выключена.
- В Windows включено «Планирование графического процессора с аппаратным ускорением».
- [ScriptHookRDR2](http://dev-c.com/rdr2/scripthookrdr2/) с его загрузчиком ASI (`dinput8.dll`) или другой загрузчик ASI плюс ScriptHookRDR2.

## Установка

Игра должна быть закрыта.

1. Скачайте `RDR2FrameGen-<версия>.zip` в [Releases](../../releases) и распакуйте куда угодно.
2. Запустите `install.bat`.

Установщик находит игру по записям Steam или Rockstar в реестре (иначе укажите
`-Game "<папка с RDR2.exe>"`) и кладёт в папку игры:

- `RDR2FrameGen.asi` и `RDR2FrameGen.ini` (если ini уже есть, он не перезаписывается);
- папку `RDR2FrameGen\` с библиотеками NVIDIA Streamline. В архиве мода их нет: установщик скачивает
  официальный релиз Streamline 2.14.16 с GitHub NVIDIA (около 280 МБ, один раз; кэш в
  `%LOCALAPPDATA%\RDR2FrameGen`) и достаёт из него только семь нужных файлов. Туда же копируется
  `nvngx_dlss.dll` самой игры: после подключения Streamline DLSS ищет свои библиотеки в этой папке.
  **После обновления игры или замены версии DLSS запустите установщик ещё раз.**

Удаление: убрать из папки игры `RDR2FrameGen.asi`, `RDR2FrameGen.ini`, `RDR2FrameGen.log` и папку
`RDR2FrameGen\`.

## Как пользоваться

- Генерация включается сама через полсекунды после появления в мире и выключается на экранах без
  3D-сцены (загрузки, видео), пока окно игры не в фокусе и при смене режима окна.
- **Home** выключает и включает её (клавиша меняется в ini).
- Меню и оверлея нет. Что делает мод, видно в `RDR2FrameGen.log` рядом с игрой. Проверить, что
  генерация работает, можно счётчиком FPS, который считает показанные кадры (оверлей NVIDIA, RTSS).

## Настройки (`RDR2FrameGen.ini`)

| Ключ | По умолчанию | Смысл |
|---|---|---|
| `Enabled` | `1` | `0` оставляет игру нетронутой (остаётся только запись вылетов) |
| `ToggleKey` | `0x24` (Home) | клавиша выключения и включения генерации |
| `HudLess` | `1` | отдавать DLSS-G кадр без интерфейса; `0` только для сравнения |
| `CameraNear`, `CameraFar` | `0.15`, `10000` | плоскости отсечения камеры в метрах; игра их не сообщает |
| `CameraDelay` | `1` | на сколько тиков игры замер камеры отстаёт от самого свежего (чтобы замеры шли в ногу с кадрами) |
| `DebugLogging` | `0` | подробная диагностика в лог; клавиша End тогда пишет проходы рендера двух кадров |

## Ограничения

- Трава, частицы и вода могут слегка двоиться: у самой игры для них нет векторов движения.
- Карта и меню паузы считаются интерфейсом и идут с исходной частотой кадров.
- При базовой частоте ниже примерно 45 кадров артефакты заметнее, это свойство самого DLSS-G.
- Только 2x. Без мультигенерации и без поддержки других видеокарт.
- Проверено на RDR2 1.0.1491.50 (Steam), Streamline 2.14.16, RTX 4070, драйвер 621.24, вместе с
  примерно 30 другими модами. Другие версии игры могут работать, но не проверялись.

## Если игра вылетает

Мод записывает любой вылет процесса игры в `RDR2FrameGen.log` (модуль и смещение, стек вызовов),
в том числе при `Enabled=0`. Приложите этот лог к issue. Вылет, в стеке которого только `RDR2.exe`,
обычно вызван игрой или другим модом; точно это покажет запуск с `Enabled=0`.

## Сборка из исходников

Нужны Visual Studio 2022 (нагрузка «Разработка классических приложений на C++») и CMake 3.25+.

```bat
powershell -ExecutionPolicy Bypass -File tools\fetch-streamline.ps1
cmake -S . -B build -A x64
cmake --build build --config Release
powershell -ExecutionPolicy Bypass -File install.ps1
```

`tools\fetch-streamline.ps1` распаковывает Streamline SDK в `external\streamline` (или укажите CMake
свою копию: `-DSTREAMLINE_SDK=<папка>`). Заголовки Vulkan берутся из `%VULKAN_SDK%`, если Vulkan SDK
установлен, иначе CMake скачивает их сам. `install.ps1 -Development` ставит отладочные библиотеки
Streamline с оверлеем NVIDIA для проверки входных данных. `tools\package.ps1` собирает архив релиза.
